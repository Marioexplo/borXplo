By default, you give informations to borXplo about what you want to back up in ~/.config/borXplo/config.json .
The configuration file always has to be formatted in the JSON language.
Here are the values presented as parsed for Python and explained:

target_label: str           # specifically ID_FS_LABEL for udev. It's usually the name that appears in file managers
only_usb: bool = False      # wether to consider only USB devices when checking labels
target_node: str            # as in /dev/... If this option is set, target_label is not considered
directory: str              # the directory inside the device in which to put the repo
quota: float = ∞            # maximum space occupied by the repo in Gb
progress: bool = True       # wether to show progress
stats: bool = False         # wether to show statistics
compression: str            # execute 'borg help compression' for details
max_archives: int           # when number of archives passes this limit, they repository is compacted
unmount: bool = False       # wether to unmount the target when the backup process has finished
repos: list[dict]           # which of your repositories to back up (see below)

Repo:
    path: str               # must be set. This is read relatively from the HOME directory.
    include: list[str]      # only the paths in the list will be included. Supports shell-like patterns, read from 'path'.
                            # Note that with this, a path that doesn't exist will just be ignored
    exclude: list[str]      # uses fnmatch patterns
    patterns: list[str]     # see 'borg help patterns' for advanced usage. Unlike Borg, 'sh:' is not implicit and
                            # can't be omitted and syntax prefixes R and P are not available
    git: bool = False       # just the git repository will be backed up
    directories: list[str]  # with this option, the program will run for all the given directories in 'path'
                            # if a file is given, an error will be returned
include, exclude, patterns and directories are read from 'path'.
'path' and 'include' resolve symlinks.
If 'include' or 'git' are set, 'path' will not be included.
If you exclude a directory with 'exclude', even if you put a path inside that directory in a 'path' or 'include' of any Repo, that path will still be ignored. To include it you must use 'patterns', e.g. if you wanted to exclude only the directory "Python" inside "Projects" but keep "Python/borXplo", your Repo would look like this: {"path":"Projects","patterns":["+ sh:Python/borXplo","- sh:Python"]}

Here's an example:
{
    "target_label": "Marioexplo pen-drive",
    "only_usb": true,
    "directory": "backup",
    "compression": "lzma,8",
    "repos": [
        {
            "path": ".config"
        },
        {
            "path": "Projects",
            "directories": [
                "Python",
                "C#"
            ],
            "git": true,
            "include": [
                "memo.txt"
            ]
        }
    ],
    "unmount": true
}
