Usage: borxplo [--path PATH] [--config PATH] [--gui]
    Back up your data reading the options in ~/.config/borXplo/config.json
    The following options work only per execution:
    --path                  overrides the path of the repositoy for the files already backed up
    --config                overrides the path of the configuration file
    --gui                   open with GUI

Usage: borxplo COMMAND
    COMMAND can be one of the following options:
        help                shows this message

        guide               shows a guide of the configuration file

        automatic [-t|--terminal] DAYS
                            handles the option to automatically open the GUI when the system powers on
            -t|--terminal   print the messages of the backup process to a terminal
                            if the option had been enabled and it is not given again, it disables
            DAYS            the amount of days after which to remember to back up
                            if it's less than 1, the option is deactivated

        check [-d|--days DAYS] [--no-gui]
                            check if it's time to back up. This command is used by the 'automatic' option

            -d|--days       override DAYS from 'automatic'
            DAYS            the amount of days that need to have passed to back up
            --no-gui        do not display the GUI before backing up
